What's inside




🔁 Cross-resolver drift detection
Diffs every record across every resolver. A stale propagation at one DNS provider shows up in seconds — try the drift toggle above.


🚦 Clean exit codes
0 healthy · 2 drift · 3 failure · 64 bad args. Drops into cron or any monitor without parsing a single line of output.


🐍 Single file, stdlib only
One Python file, zero dependencies beyond the standard library. scp it onto any box and run.


🔒 All 6 record types × 8 resolvers

🔒 Timestamped history
Every run appends a timestamped entry to a local JSONL log, so slow DNS changes become visible over days. In the full kit.




How it runs




# dns_health.py — the whole config surface (5 of ~40 lines in the full kit)
DOMAINS   = ['example.com', 'api.example.com']
RESOLVERS = ['8.8.8.8', '1.1.1.1', '9.9.9.9', '208.67.222.222']
RECORDS   = ['A', 'AAAA', 'MX', 'TXT', 'NS', 'CNAME']

# crontab — alerts on any non-zero exit
*/10 * * * * python3 /opt/dns_health.py --quiet || mail -s 'DNS drift' you@ops.io
